# ZeroTalk Project Directives
- **Core Principle:** Zero external third-party dependencies (BCL only on .NET Framework 4.8).
- **Communication Architecture:** TCP Server-Client for authentication, signaling, and chat history; P2P UDP with STUN hole punching for real-time video streaming with TCP relay fallback.
- **Security:** ECDH (Elliptic Curve Diffie-Hellman 256) key exchange + AES-256-CBC for end-to-end message encryption; SHA-256 for password hashing.
- **UI & Controls:** Adhere strictly to `[AgentOption]/standards/csharp/winforms.md` (BaseForm, RunAfterShown, no Form_Load).
- **Packaging:** Adhere to dual release packaging (Full vs Lite) via `scripts/publish-app.ps1`.
